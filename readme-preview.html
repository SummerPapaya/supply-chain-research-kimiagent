Overview

This repository contains a fully self-contained interactive research report on the global supply chain management industry at mid-2026. It is not a web app framework — it is a single editorial product: hand-built HTML, vanilla JavaScript, and D3.js visualizations, bundled into one portable HTML file.

The report examines three layers of the supply chain industry:

LayerWhat it isSizeGrowth
PhysicalShips, ports, warehouses, trucks$11.97TCyclical
PlanningSCM software (planning, execution, WMS/TMS)$39.2B (2026)+10.7% CAGR
AutomationWarehouse robotics & automation~$29BMid-teens CAGR

The physical network is being re-priced by policy — a 15% EU–US tariff baseline, a half-blockaded Suez Canal, and carbon that now carries a cash cost. The planning layer is being rebuilt around agentic AI, with 51% of chief supply-chain officers already piloting autonomous decision agents.

Tech stack

Frontend Vanilla HTML / CSS / JavaScript (no framework, no build step) Visualization D3.js v7 · TopoJSON · HTML Canvas Bundling Python 3 script (bundle.py → dist-single.html) Data Inline JSON in data.js (no backend, no database) Live quotes stooq.com public CSV endpoints (no API key) i18n Custom bilingual system (EN / 中文) with runtime toggle Fonts ET Book (base64-inlined, CSP-safe)

Zero dependencies at runtime — vendor/ ships d3.min.js and topojson-client.min.js. Everything else is hand-rolled.

Data & methodology

  • Market data marked to the 2026-07-17 close
  • YTD indexes are weekly closes rebased to 100
  • Source register (K1–K24) documents every number with dated sources
  • Scenario probabilities are subjective research judgments, not market-implied odds
  • No ratings, no price targets, no investment advice

Live data

The §3 refresh widget pulls real-time stock quotes from stooq.com — a public CSV endpoint requiring no API key and no authentication. It covers 12 entities:

UPS · FDX · DHL.DE · EXPD · CHRW · JBHT · XPO · GXO · ZIM · MAERSK-B.CO · MANH · ^SPX

Behavior: 9-second timeout per request; results cached to localStorage; on failure, a visible label says "LIVE ENDPOINT UNREACHABLE — SHOWING VERIFIED SNAPSHOT" and falls back to the Jul 17 close. Never silently substitutes stale data.

Internationalization

The report is bilingual — English and Chinese (中文) — with a runtime toggle (top-right button). Every text string, chart label, and source citation has a paired translation. The choice persists in localStorage as scm-lang.

项目概览

本仓库包含一份完全自包含的交互式研究报告，聚焦2026年年中的全球供应链管理行业。它不是 Web 应用框架——而是一个完整的编辑产品：手工编写的 HTML、原生 JavaScript 和 D3.js 可视化，打包为一个可移植的 HTML 文件。

报告审视了供应链行业的三个层级：

层级定义规模增速
实体层船舶、港口、仓库、卡车$11.97T周期性
计划层SCM软件（计划、执行、仓储/运输管理）$39.2B（2026）+10.7% 复合增速
自动化层仓储机器人与自动化约$29B复合增速15%左右

实体网络正被政策重新定价——15%的美欧基准关税、半封锁的苏伊士运河、以及如今带有现金成本的碳排放。计划层正围绕智能体AI重构，51%的首席供应链官已在试点自主决策代理。

数据与方法

  • 市场数据标记至2026年7月17日收盘价
  • YTD指数为每周收盘价，重定基为100
  • 来源登记册（K1–K24）记录每个数字的注明日期的来源
  • 情景概率是主观研究判断，不是市场隐含赔率
  • 无评级、无目标价、不构成投资建议

实时数据

§3 刷新组件从 stooq.com 拉取实时股票报价——公开 CSV 接口，无需 API 密钥、无需认证。覆盖12个标的：

UPS · FDX · DHL.DE · EXPD · CHRW · JBHT · XPO · GXO · ZIM · MAERSK-B.CO · MANH · ^SPX

行为：每次请求超时9秒；结果缓存到 localStorage；失败时显示可见标签"实时端点不可达——显示已验证快照"并回退至7月17日收盘价。绝不静默替换过期数据。

国际化

报告支持双语——英文与中文——通过右上角按钮运行时切换。每个文本字符串、图表标签和来源引用都有配对翻译。选择持久化到 localStorage 的 scm-lang。
